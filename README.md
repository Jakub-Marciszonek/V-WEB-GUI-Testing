# Hex to RGB Converter

This project is a simple web application that converts hexadecimal color values to their corresponding RGB values. It includes a user interface for input and output, along with unit tests to ensure the conversion logic works correctly.

## Features

- **Hexadecimal to RGB Conversion**: Converts colors entered in `#RRGGBB` or `#RGB` format to RGB values.
- **Error Handling**: Handles invalid input gracefully, including non-string inputs and unsupported formats.
- **Unit Tests**: Provides unit tests to validate the conversion function.

## Installation

No additional installation is required for this project. Simply open `index.html` in a web browser to use the application.

## Usage

1. Open `index.html` in your web browser.
2. Enter a hex color in the input field.
3. Click the "Convert" button.
4. The RGB values will be displayed below the input field.

## Running Tests

To run the unit tests, ensure you have Node.js and npm installed. Follow these steps:

1. Install dependencies:
    ```sh
    npm install
    ```

2. Run the tests:
    ```sh
    npm test
    ```
